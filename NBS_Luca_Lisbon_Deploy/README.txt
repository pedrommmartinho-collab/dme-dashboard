NBS Portugal - Luca in Lisbon

DEPLOYMENT
1. Upload the CONTENTS of this folder to any static web host.
2. Keep index.html and luca_in_lisbon_comic_4k.png in the same directory.
3. Open the site's root URL. index.html is the entry page.

Works with static hosting such as Netlify, Vercel, GitHub Pages, Azure Static Web Apps, or a standard web server.
No build step, server-side code, database, or external JavaScript libraries are required.

CONTROLS
- ENTER starts the experience
- NEXT / right arrow / space advances
- left arrow goes back
- F requests browser fullscreen
